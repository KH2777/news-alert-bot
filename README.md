# Market Alert Bot 🛡

Telegram-бот для риск-менеджера: заранее (по умолчанию **за 60 минут**) предупреждает о событиях,
которые двигают крипту, forex, индексы и сырьё, — чтобы успеть срезать плечи.

**Что отслеживает**
- **Экономический календарь** (ForexFactory): ФРС/ЕЦБ/BoE/BoJ, NFP, CPI, PCE, ВВП, розница, OPEC+ и т.д.
- **Расписание Трампа** (публичный график Белого дома через Roll Call Factba.se): обращения, пресс-конференции,
  выступления, подписание указов, саммиты. Протокольные пункты («вылетает», «обед», «Executive Time») отфильтрованы.

- **Truth Social** — новые посты Трампа (через архив trumpstruth.org, запасной источник — API Truth Social).

**Что присылает**
1. ☀️ **Утренний дайджест** в 07:00 — все события дня (включая выступления Трампа с ещё неизвестным временем).
2. 🌙 **Вечерний план на завтра** в 21:00.
3. ⚠️ **Предупреждение за 60 мин** — событие, прогноз/предыдущее, уровень импакта, какие инструменты заденет, что делать с риском.
4. ⏰ **Финальное напоминание за 15 мин** — только для критических событий.
5. 🚨 **Посты Трампа о рынках** (тарифы, ФРС, Китай, нефть, крипта, война, санкции…) — через 0–10 мин после публикации.
6. 🆕 **Новые пункты в расписании Трампа** — как только Белый дом их опубликовал.
7. ⚡ **Резкие движения цены** — BTC, ETH, S&P 500, Nasdaq, золото, нефть, DXY, EUR/USD, USD/JPY: если инструмент прошёл больше порога за 15 или 60 минут — сообщение с вероятной причиной (событие из календаря или пост Трампа).
8. 📊 **Итог после события** — через 10 мин после важного события: как отреагировали инструменты, размах, и вывод — можно ли возвращать плечи.
9. 🗓 **Обзор недели** — в воскресенье в 18:00: все важные события, опасные дни, центробанки, план по риску.
10. Команды: `/next`, `/today`, `/tomorrow`, `/week`, `/truth`, `/market`, `/help` (ответ в течение ~5 минут).

Пороги «резкого движения» за 15 мин: BTC 1.5%, ETH 2%, S&P 0.6%, Nasdaq 0.8%, золото 0.7%, нефть 1.5%, DXY 0.35%, EUR/USD 0.35%, USD/JPY 0.5% (за 60 мин — в 1.8 раза больше). Меняются в `prices.py` или общим множителем `PRICE_SENSITIVITY`.

Ночью (`QUIET_HOURS`, по умолчанию 0–7) некритичные сообщения приходят без звука; критические — всегда со звуком.

Уровни импакта: 🔴🔴 критический · 🔴 высокий · 🟠 средний. Правила лежат в `impact.py` — их легко подстроить под свою книгу.

## Установка (≈10 минут)

### 1. Создать бота в Telegram
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя → получите **токен** вида `123456:ABC...`.
2. Напишите своему боту любое сообщение (например `/start`).
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}` — это **chat id**.
   Для группы: добавьте бота в группу, напишите в ней сообщение, id будет отрицательным (`-100...`).

### 2. Залить код на GitHub
1. Создайте **публичный** репозиторий (для публичных Actions бесплатны без лимита; токены хранятся в Secrets и не видны) на github.com.
2. Загрузите туда все файлы из этой папки (включая скрытую папку `.github/workflows`).
   Проще всего: *Add file → Upload files* и перетащить содержимое папки.

### 3. Добавить секреты
*Settings → Secrets and variables → Actions → New repository secret:*

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | ваш chat id |
| `ANTHROPIC_API_KEY` | *необязательно* — добавляет к каждому алерту короткий AI-разбор сценариев |

### 4. Включить и проверить
*Actions → Market event alerts → Run workflow.* В логе будет строка `загружено N событий`.
Дальше бот запускается сам каждые 5 минут.

## Настройки (необязательно)
*Settings → Secrets and variables → Actions → вкладка Variables:*

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `DISPLAY_TZ` | `Europe/London` | Часовой пояс в сообщениях (`Europe/Kyiv`, `Europe/Warsaw`…) |
| `LEAD_MINUTES` | `60` | За сколько минут основное предупреждение |
| `FINAL_MINUTES` | `15` | Финальное напоминание (`0` — выключить) |
| `MIN_LEVEL` | `2` | `1` — слать и средние события, `3` — только критические |
| `DIGEST_HOUR` | `7` | Час утреннего дайджеста (`-1` — выключить) |
| `EVENING_HOUR` | `21` | Час вечернего плана на завтра (`-1` — выключить) |
| `QUIET_HOURS` | `0-7` | Часы, когда некритичное приходит без звука |
| `TRUMP_SENSITIVE` | `1` | `1` — алерт о любом публичном событии Трампа с прессой; `0` — только по ключевым темам |
| `TRUTH_ENABLED` | `1` | `0` — выключить мониторинг Truth Social |
| `PRICE_ALERTS` | `1` | `0` — выключить алерты о движении цены |
| `PRICE_SENSITIVITY` | `1.0` | `0.7` — алерты чаще, `1.5` — только сильные движения |
| `REPORT_MIN_LEVEL` | `2` | Для каких событий слать итог (`3` — только критические, `0` — выкл) |
| `WEEKLY_DAY` / `WEEKLY_HOUR` | `6` / `18` | День (0=Пн … 6=Вс) и час обзора недели; `WEEKLY_DAY=-1` — выкл |
| `TRUTH_MIN_LEVEL` | `2` | `0` — присылать все посты (нерыночные без звука), `3` — только самые опасные |

Список валют — переменная окружения `COUNTRIES` в `bot.py` (по умолчанию USD, EUR, GBP, JPY, CNY, CAD, AUD, CHF, OPEC).

## Проверка локально
```bash
pip install -r requirements.txt
DRY_RUN=1 python bot.py          # печатает сообщения в консоль вместо Telegram
```

## Важные ограничения
- **GitHub может задерживать запуски по расписанию на несколько минут** (в часы пик и дольше). Поэтому предупреждение
  приходит примерно за 45–60 минут, а не ровно за 60. Если нужна точность до минуты — запустите тот же `bot.py`
  через cron на VPS (`*/5 * * * * cd /path && python3 bot.py`).
- **Посты в Truth Social бот видит постфактум** — с задержкой 0–10 мин (частота запуска + задержка архива). Спонтанные ответы журналистам и ТВ-интервью бот не видит.
- У части выступлений Трампа время объявляют поздно («TBD»). Такие события попадают в утренний дайджест,
  а алерт за час придёт, как только Белый дом опубликует время.
- Время выступлений за пределами США может указываться по местному времени — бот пересчитывает известные пояса
  и помечает ⚠️ остальные.
- GitHub отключает расписание в репозиториях без активности 60 дней; бот сам коммитит `state.json`, но если
  уведомления пропали — проверьте вкладку Actions.
- Котировки: Coinbase (крипта) и Yahoo Finance (фьючерсы, FX) — бесплатные, неофициальные, с задержкой до нескольких минут. Фактические значения статистики (actual) бесплатный календарь не публикует — итог после события строится по реакции рынка.
- Источники бесплатные и неофициальные: перед ключевыми событиями (FOMC, NFP) стоит сверяться с основным терминалом.
